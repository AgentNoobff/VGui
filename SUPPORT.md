# Support

Start with the [GitHub Wiki](https://github.com/AgentNoobff/VGUI/wiki), especially [Installation](https://github.com/AgentNoobff/VGUI/wiki/Installation) and [Troubleshooting](https://github.com/AgentNoobff/VGUI/wiki/Troubleshooting).

For reproducible defects, open a bug report and include:

- VGui release tag or commit
- Velocity, Java, PacketEvents, Minecraft client, and backend versions
- the smallest code sample that reproduces the behavior
- relevant logs with credentials and private addresses removed
- whether the issue occurs with the standalone plugin, a shaded copy, or both

Use GitHub Discussions for usage questions and design help once Discussions are available. Use [private vulnerability reporting](https://github.com/AgentNoobff/VGUI/security/advisories/new) for security issues.
